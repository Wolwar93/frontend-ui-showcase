# Интерактивная сетка карточек (Interactive Card Grid)

Самостоятельный интерфейсный блок с асимметричной сеткой и модальными окнами, адаптированный из секции форматов проекта **MINATAVR**.

## Возможности
- **Layout:** CSS Grid на 12 колонок с адаптивными композициями для Desktop, Tablet и Mobile устройств.
- **Интерактив:** Эффекты при наведении (Hover) и фокусе с клавиатуры для карточек.
- **Модальные окна:** Реализовано на нативном теге `<dialog>` (закрытие по клику на бэкдроп, кнопке или клавише Escape; автоматический возврат фокуса).
- **Менеджмент скролла:** Блокировка прокрутки основной страницы (`overflow: hidden` для `body`) при открытом модальном окне с сохранением независимого скролла внутри окна.
- **Оптимизация:** Интегрирована поддержка медиавыражения `prefers-reduced-motion` для пользователей, чувствительных к анимации.

## Запуск
Откройте `index.html` в браузере. Оригинальный коммерческий контент и изображения заменены на нейтральные градиенты и текст-рыбу.

## Структура файлов
- `index.html` — разметка сетки и модальных окон.
- `style.css` — адаптивные стили Grid-системы и кастомизация диалоговых окон.
- `script.js` — управление данными карточек и логика обработки событий модального интерфейса.

## Архитектура проекта
Компонент выделен из реального коммерческого проекта и адаптирован для демонстрации в портфолио. Архитектура кода оптимизирована с привлечением AI-инструментов, протестирована вручную на предмет утечек фокуса и кроссбраузерной совместимости логики скролла.
