# UI-компоненты — HTML, CSS, JavaScript

Коллекция из четырёх самостоятельных интерактивных компонентов, выделенных и адаптированных из реальных веб-проектов для демонстрации навыков адаптивной вёрстки и работы с JavaScript.

Каждый пример можно открыть отдельно в браузере. Для запуска не нужны фреймворки, npm, сборка или серверная часть.

## Компоненты

| Компонент | Что демонстрирует | Источник |
| --- | --- | --- |
| [Навигация по главам](interactive-chapter-navigation/) | Переключение семи глав, анимированная область чтения на Desktop и аккордеон на небольших экранах | Three Sides Horizon — страница «Манифест» |
| [Адаптивная навигация](responsive-navigation/) | Бургер-меню, закрытие по Escape и клику вне меню, отслеживание активного раздела, якорная навигация | IQCHISTKA |
| [Интерактивная сетка карточек](interactive-card-grid/) | Асимметричный CSS Grid, адаптивные композиции, модальные окна на `<dialog>`. Реализовано ручное управление скроллом (поддержка `overflow: hidden` для `body`) при открытии модальных окон. | MINATAVR — страница тренировок |
| [Слайдер «До / После»](before-after-slider/) | Сравнение изображений с помощью `input[type="range"]`, `clip-path` и CSS-переменной | IQCHISTKA |

## Как посмотреть

1. Скачайте репозиторий или клонируйте его через Git.
2. Откройте `index.html` внутри интересующей папки в браузере.
3. Изменяйте ширину окна, проверяйте интерактив мышью, касанием и клавиатурой.

Все демонстрационные ресурсы находятся в соответствующих папках. Каждый компонент также содержит собственный `README.md` с описанием механики.

## Стек

**HTML5 · CSS3 · CSS Grid · JavaScript (Vanilla JS) · адаптивная вёрстка · доступность интерфейсов**.

Примеры используют нативные возможности браузера: `<dialog>`, `matchMedia`, `aria-*`, `input[type="range"]`, CSS custom properties и медиазапросы. В отдельных компонентах предусмотрена поддержка `prefers-reduced-motion`.

## О происхождении кода

Представленные компоненты изолированы и адаптированы из реальных проектов для демонстрации интерфейсной логики. В целях соблюдения NDA (соглашения о неразглашении) и защиты авторских прав заказчиков, все уникальные текстовые, визуальные и брендовые данные были удалены или заменены на независимые шаблоны.

Инженерный пайплайн:
Разработка, рефакторинг и оптимизация данных компонентов велись с привлечением современных AI-инструментов (Claude, Codex). Весь сгенерированный код проходил обязательную ручную валидацию, код-ревью и адаптацию под задачи конкретных интерфейсов, обеспечивая стабильную кроссбраузерную работу и аккуратную структуру файлов.
