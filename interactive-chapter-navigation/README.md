# Интерактивная навигация по главам (Chapter Navigation)

Самостоятельный комплексный UI-компонент навигации по лонгридам, изолированный из страницы «Манифест» проекта **Three Sides Horizon**.

## Возможности
- **Интерактив:** Семь переключаемых контентных глав и динамический счётчик активного раздела.
- **Десктопный UX:** Изолированная область чтения на Desktop с плавным переключением и анимированной сменой содержимого.
- **Мобильный UX:** Автоматическая трансформация интерфейса в паттерн «Аккордеон» на планшетах, смартфонах и экранах с небольшой высотой (Landscape-ориентация).
- **Доступность:** Полное управление с клавиатуры, корректное обновление состояний `aria-expanded` и поддержка режима `prefers-reduced-motion`.

## Запуск
Откройте `index.html` в браузере. Компонент полностью автономен и не требует локального сервера или сборки.

## Архитектура проекта
Компонент адаптирован для портфолио с заменой исходных текстов на демонстрационные шаблоны. Рефакторинг и приведение кодовой базы к изолированному виду выполнены с использованием AI-инструментов. Логика отображения и переключения состояний полностью отлажена вручную.
