# Слайдер «До / После» (Before-After Slider)

Самостоятельный адаптивный компонент сравнения изображений, изолированный и оптимизированный на основе логики проекта **IQCHISTKA**.

## Возможности
- **Механика обрезки:** Два совмещённых слоя; верхнее изображение открывается с помощью нативного `clip-path` и динамической CSS-переменной `--position`.
- **Интерактивность:** Нативный `input[type="range"]` для бесшовного управления мышью, тач-событиями и стрелками клавиатуры.
- **Доступность (Accessibility):** Доступная подпись элемента, динамически обновляемый `aria-valuetext` и кастомный индикатор фокуса.
- **Производительность:** Адаптивная вёрстка на чистом CSS/JS без сторонних библиотек, сборщиков и внешних зависимостей.
- **Графика:** Исходные коммерческие материалы заказчика заменены на независимые демонстрационные SVG-иллюстрации.

## Запуск
Откройте `index.html` локально в любом современном браузере.

## Структура файлов
- `index.html` — семантическая разметка компонента.
- `style.css` — стили, адаптивная сетка и механизм обрезки (clipping).
- `script.js` — легковесный скрипт синхронизации положения разделителя с CSS-переменной.
- `assets/` — демонстрационная векторная графика (`before.svg`, `after.svg`).

## Архитектура проекта
Компонент спроектирован на основе коммерческого кейса. В процессе оптимизации и рефакторинга кодовой базы применялись современные AI-инструменты для сокращения рутинного кода. Архитектура и логика полностью валидированы вручную.
