# Адаптивная навигация (Responsive Navigation)

Самостоятельный отзывчивый компонент главного меню сайта с фиксированной шапкой и якорной логикой, выделенный из проекта **IQCHISTKA**.

## Возможности
- **Адаптивность:** Полноразмерное горизонтальное меню на Desktop и автоматическая перестройка в мобильный интерфейс на брейкпоинте 1024px и ниже.
- **Анимации:** Плавная CSS-трансформация иконки бургера в крестик; состояние интерфейса контролируется единым классом `.menu-open`.
- **UX-сценарии:** Автоматическое закрытие меню при выборе ссылки, клике во внешнюю область (out-of-click), нажатии клавиши Escape или изменении ширины экрана (resize).
- **Доступность (A11y):** Интеграция `aria-expanded`, доступные подписи кнопок, возврат фокуса и управление атрибутом `inert` для скрытого мобильного меню в поддерживаемых браузерах.
- **Якорная логика:** Динамическая подсветка активного раздела (Scrollspy) при прокрутке страницы и корректный отступ к якорям с учетом высоты фиксированной шапки (header).

## Запуск
Откройте `index.html` в браузере. Для полноценной отработки некоторых браузерных механик рекомендуется запуск через любой локальный статический сервер (например, Live Server в VS Code).

## Архитектура проекта
Компонент представляет собой чистую реализацию интерфейсного паттерна на базе реального коммерческого проекта. В процессе рефакторинга стилей и JS-логики применялись современные AI-инструменты под ручным контролем разработчика для обеспечения чистоты и производительности кода.
